**새로 생긴 화면**: `내 고요 기록` (주소: `/journey`). 홈 화면의 "📒 내 고요 기록" 카드를 누르면 들어가요.

**만들 때 정한 점 (쉬운 설명)**
- 도장은 **내가 직접 버튼을 눌러** 찍어요. 위치를 계속 확인하지 않아서 개인 정보를 더 걷지 않아요.
- 같은 장소라도 **같은 날, 같은 시간대**에는 도장이 한 번만 찍혀요. (도장 도배 방지)
- 미션은 따로 저장하지 않고, 도장과 위시리스트를 보고 **그때그때 계산**해요. 그래서 `gz_missions` 저장 키는 만들지 않았어요.
- 오늘의 고요 한 곳은 **날짜를 숫자로 바꿔서** 지역과 장소를 정해요. 그래서 하루 동안은 같은 곳이 나와요. 인터넷이 안 되면 카드를 숨겨요.
- 광고는 이번 기능에 **하나도 더 넣지 않았어요.** 광고 때문에 도장이나 배지를 못 받는 일은 없어요.

**배지 6종 (받는 방법)**

| 배지 | 받는 방법 |
|------|-----------|
| 🎉 첫 도장 | 처음 도장 찍기 |
| 🌅 아침 산책러 | 오전에 서로 다른 3곳 |
| 🌇 노을 수집가 | 저녁에 서로 다른 3곳 |
| ⏳ 시간 여행자 | 한 장소를 서로 다른 시간대에 2번 |
| 🗺️ 동네 탐험가 | 한 지역에서 서로 다른 5곳 |
| 🍀 사계절 친구 | 한 장소를 봄·여름·가을·겨울에 모두 |

> 아래 1~8번 내용은 만들기 전에 정리한 **기획 내용**이에요. 위 표가 실제로 만들어진 결과예요.

## 1. 왜 이 문서를 만들었나요?

"고요한 산책" 앱은 **지금 조용히 쉬기 좋은 곳**을 찾아 주는 앱이에요.
그런데 지금은 장소를 한 번 찾고 나면 앱을 다시 열 이유가 별로 없어요.

그래서 두 가지를 고민했어요.

1. **흥미**: 장소를 찾고 다녀오는 일이 더 재미있으려면 어떻게 할까?
2. **재방문**: 같은 장소에 다시 가 보고, 앱도 다시 열고 싶게 하려면 어떻게 할까?

## 2. 꼭 지켜야 할 약속 (지금 앱의 규칙)

아이디어가 아무리 좋아도, 앱이 이미 정한 규칙을 깨면 안 돼요.
(자세한 내용: [PRD_1PAGE.md](./PRD_1PAGE.md), [RISKS_AND_DECISIONS_10.md](./RISKS_AND_DECISIONS_10.md), [IAA_ADS_PLAN.md](./IAA_ADS_PLAN.md))

| 약속 | 쉬운 설명 |
|------|-----------|
| 로그인 없음 | 이름이나 전화번호를 묻지 않아요. |
| 휴대폰 안에만 저장 | 기록은 휴대폰 속 작은 저장 공간(localStorage)에만 남겨요. 서버로 보내지 않아요. |
| 푸시 알림 없음 | 앱이 먼저 "띵동!" 하고 부르지 않아요. 앱을 열었을 때만 알려 줘요. |
| 친구 공유·댓글 없음 | 지금 단계에서는 SNS 공유나 댓글 기능을 넣지 않아요. |
| 과장하지 않기 | "무조건 조용해요", "AI가 골랐어요" 같은 말은 쓰지 않아요. "대체로 ~한 편이에요"처럼 말해요. |
| 광고는 조금만 | 전면 광고는 한 번 켤 때 최대 2번, 2분 간격. 보상 광고는 사용자가 직접 버튼을 눌렀을 때만. |
| 지도 넣지 않기 | 앱 안에 지도를 넣지 않고, 길찾기는 카카오맵·네이버지도로 연결만 해요. |

## 4. 아이디어 자세히 보기

### ① 고요 도장 모으기 🟢

**어떤 기능인가요?**
장소 상세 화면에 **"다녀왔어요"** 버튼을 만들어요. 누르면 그 장소의 **도장**이 찍혀요.
도장은 지역별 **도장판**(서울, 부산, 제주 … 17개 지역)에 모여요.

**왜 재미있나요?**
- 스티커 모으기처럼 빈칸을 채우는 즐거움이 있어요.
- "제주 도장판을 다 채워 볼까?" 하는 작은 목표가 생겨요.

**왜 다시 오게 되나요?**
- 도장판의 빈칸을 보면 다음에 갈 곳이 떠올라요.

**지켜야 할 점**
- 위치 확인 없이 **스스로 누르는 방식**이에요. (위치를 계속 확인하면 권한을 많이 요구하게 돼요.)
- 도장은 휴대폰에만 저장해요.

**저장 예시 (제안)**: `gz_stamps` → `{ contentId, areaCode, visitedAt, timeSlot }[]`

---

### ② 시간 여행자 배지 🟢

**어떤 기능인가요?**
이 앱은 **오전 / 오후 / 저녁 / 지금** 시간대를 고를 수 있어요.
같은 장소를 **다른 시간대**에 다녀오면 배지를 줘요.

| 배지 이름 | 받는 방법 |
|-----------|-----------|
| 🌅 아침 산책러 | 오전에 다녀온 곳 3곳 |
| 🌇 노을 수집가 | 저녁에 다녀온 곳 3곳 |
| ⏳ 시간 여행자 | 한 장소를 서로 다른 시간대 2번 이상 |
| 🗺️ 동네 탐험가 | 한 지역에서 5곳 |

**왜 다시 오게 되나요?**
- "아침에 갔던 공원, 저녁엔 어떤 느낌일까?" 하고 **같은 장소에 다시 가게** 만들어요.
- 이미 있는 시간대 기능([RECOMMENDATION_RULES.md](./RECOMMENDATION_RULES.md))을 그대로 활용해요.

**지켜야 할 점**
- 배지 설명에도 "저녁엔 분위기가 **달라질 수 있어요**"처럼 조심스러운 말을 써요.

---

### ③ 오늘의 고요 한 곳 🟢

**어떤 기능인가요?**
홈 화면 맨 위에 **매일 바뀌는 장소 1곳**을 보여 줘요.
날짜를 기준으로 고르기 때문에 하루 동안은 같은 장소가 나와요.

**왜 다시 오게 되나요?**
- "오늘은 어디가 나왔을까?" 궁금해서 매일 열어 보게 돼요.
- 뽑기 상자를 여는 것 같은 작은 설렘이 있어요.

**지켜야 할 점**
- "오늘 가장 조용한 곳"이라고 하면 **과장**이에요.
  → "오늘 한번 들러 보면 좋을 곳이에요" 정도로 말해요.
- 이미 불러온 장소 목록(캐시)에서 고르면 API를 더 부르지 않아도 돼요.

---

### ④ 사계절 다시 가기 🟢

**어떤 기능인가요?**
도장을 찍을 때 **계절(봄·여름·가을·겨울)**도 같이 기록해요.
한 장소에서 4계절 도장을 모두 모으면 **"사계절 친구"** 표시가 생겨요.

**왜 다시 오게 되나요?**
- 같은 숲길도 봄에는 꽃, 가을에는 단풍이 있어서 느낌이 달라요.
- 1년 동안 천천히 다시 찾게 만드는 **긴 목표**예요.

---

### ⑤ 한 줄 고요 노트 🟢

**어떤 기능인가요?**
도장을 찍을 때 **100자 이하** 짧은 메모를 남길 수 있어요.
예: "벤치 옆 나무 그늘이 시원했다", "오전엔 새소리만 들렸다"

**왜 재미있나요?**
- 나만 보는 작은 일기장이 생겨요.
- 나중에 다시 읽으면 그때 기분이 떠올라요.

**지켜야 할 점**
- 다른 사람에게 보이지 않아요. (댓글 기능이 아니에요.)
- 100자 제한은 [DATA_MODEL.md](./DATA_MODEL.md)의 feedback 설계와 같은 기준이에요.

---

### ⑥ "다시 가 볼까요?" 카드 🟢

**어떤 기능인가요?**
앱을 열었을 때, 오래전에 다녀온 장소를 살짝 알려 줘요.

> 🍂 "30일 전에 다녀온 **○○ 공원**, 계절이 바뀌었어요. 다시 가 볼까요?"

**왜 다시 오게 되나요?**
- 좋았던 장소를 잊지 않게 도와줘요.

**지켜야 할 점**
- **푸시 알림이 아니에요.** 사용자가 앱을 열었을 때만 보여요.
- 하루에 1번만, 닫기 버튼을 누르면 그날은 다시 안 보여요.

---

### ⑦ 이번 주 작은 미션 🟢

**어떤 기능인가요?**
매주 쉬운 미션 1~2개를 보여 줘요.

| 미션 예시 |
|-----------|
| 이번 주 오전에 조용한 곳 1곳 다녀오기 |
| 가 본 적 없는 지역 장소 1곳 위시리스트에 담기 |
| 위시리스트에 담아 둔 곳 중 1곳 다녀오기 |

**왜 재미있나요?**
- 숙제가 아니라 **가벼운 놀이**처럼 느껴지게 해요.
- 위시리스트에만 있던 장소를 실제로 가게 도와줘요.

**지켜야 할 점**
- 미션을 못 해도 벌점이나 손해가 없어요.
- "매일 꼭 들어오세요" 같은 부담 주는 말은 쓰지 않아요.

---

### ⑧ 나의 산책 한 달 리포트 🟢

**어떤 기능인가요?**
한 달 동안 모은 기록을 그림 카드처럼 보여 줘요.

> 📒 이번 달 고요 기록
> - 다녀온 곳: 4곳
> - 가장 많이 간 시간대: 🌅 오전
> - 새로 받은 배지: 아침 산책러

**왜 다시 오게 되나요?**
- 내가 얼마나 쉬어 왔는지 보면 뿌듯해서 또 기록하고 싶어져요.

---

### ⑨ 내 조용함 투표 돌려받기 🔜 (v2)

**어떤 기능인가요?**
v2에서 조용함 투표(1~5점)가 다시 생기면,
"당신의 투표가 이 장소 점수에 반영됐어요"라고 알려 줘요.

**왜 지금은 안 되나요?**
- 투표 기능은 서버와 데이터베이스가 필요해서 v2로 미뤄져 있어요. ([RISKS_AND_DECISIONS_10.md](./RISKS_AND_DECISIONS_10.md)의 D-09)

## 5. 광고와 함께 쓸 때의 규칙

재미 기능에 광고를 섞을 수도 있지만, **광고 때문에 재미가 줄어들면 안 돼요.**

| 해도 되는 것 | 하면 안 되는 것 |
|--------------|-----------------|
| "광고 보고 지난달 리포트 다시 보기"처럼 **사용자가 직접 고르는** 보상형 광고 | 도장 찍을 때마다 전면 광고 띄우기 |
| 광고가 실패해도 기능은 그냥 열어 주기 | 광고를 안 보면 도장·배지를 못 받게 하기 |
| 기존 빈도 규칙(세션 2회, 2분 간격) 지키기 | 배지 받는 순간에 광고로 축하 화면 가리기 |

## 6. 만드는 순서 제안

한꺼번에 다 만들지 않고, 작게 만들어서 반응을 보고 늘려 가요.

| 단계 | 넣을 기능 | 이유 |
|------|-----------|------|
| 1단계 | ① 고요 도장 + ③ 오늘의 고요 한 곳 | 만들기 쉽고, 다른 기능의 바탕이 돼요. |
| 2단계 | ② 시간 여행자 배지 + ⑤ 한 줄 노트 + ⑥ 다시 가 볼까요 카드 | 도장 기록을 활용해서 재방문을 늘려요. |
| 3단계 | ④ 사계절 다시 가기 + ⑦ 주간 미션 + ⑧ 한 달 리포트 | 오래 쓰는 사용자를 위한 긴 목표예요. |
| v2 | ⑨ 투표 돌려받기 | 서버·투표 기능이 생긴 다음에 만들어요. |

## 7. 잘 되고 있는지 어떻게 알까요?

지금 앱에는 사용 기록을 서버로 모으는 기능이 없어요.
그래서 처음에는 아래처럼 **간단한 숫자**를 보고 판단해요.

| 궁금한 점 | 볼 수 있는 숫자 (예시) |
|-----------|------------------------|
| 도장 기능을 쓰나요? | 도장을 1개 이상 찍은 사용자 비율 |
| 다시 오나요? | 일주일 안에 앱을 다시 연 비율 (토스 파트너 콘솔 통계 활용) |
| 같은 장소에 다시 가나요? | 한 장소에 도장이 2개 이상인 경우 |

> 휴대폰에 저장된 개인 기록은 밖으로 보내지 않는다는 약속을 지키면서 확인할 방법을 따로 정해야 해요.

---

## 8. 저장할 데이터 이름 (제안)

모두 휴대폰 안(localStorage)에만 저장해요. [DATA_MODEL.md](./DATA_MODEL.md)의 `gz_` 이름 규칙을 따라요.

| 키 (제안) | 담는 내용 |
|-----------|-----------|
| `gz_stamps` | 다녀온 장소 도장 목록 (장소, 지역, 날짜, 시간대, 계절, 한 줄 노트) |
| `gz_badges` | 받은 배지 목록과 받은 날짜 |
| `gz_revisit_card_seen` | "다시 가 볼까요?" 카드를 닫은 날짜 (그날은 다시 안 보여요) |

> 이번 주 미션은 도장·위시리스트로 계산해서 따로 저장하지 않아요.

> 설정 화면의 **"전체 데이터 초기화"** 를 누르면 이 기록도 함께 지워져요. (구현 완료)

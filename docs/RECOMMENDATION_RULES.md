# 추천 규칙 — Gozneok Lite

## 1. Quiet Score (조용함 지수)

### 계산 방식
베이지안 평균 보정을 사용해 콜드스타트 문제를 완화합니다.

$$
\text{score} = \frac{m \times C + \sum votes}{m + n}
$$

| 변수 | 값 | 설명 |
|------|----|------|
| `C` | 3.5 | 전역 평균 (초기값) |
| `m` | 10 | 최소 신뢰 표본 수 |
| `n` | 투표 수 | 해당 장소 실제 투표 수 |
| `sumVotes` | 합계 | 투표 점수 합산 |

**콜드스타트 예시**: 투표 0개 → score = 3.5 (중립값)

### 점수 → 레이블 (단정 표현 금지)

| 점수 범위 | 레이블 |
|-----------|--------|
| 4.3 이상 | 대체로 매우 조용한 편이에요 |
| 3.5 ~ 4.3 | 비교적 조용한 경향이 있어요 |
| 2.7 ~ 3.5 | 보통 수준인 편이에요 |
| 2.0 ~ 2.7 | 다소 혼잡할 수 있어요 |
| 2.0 미만 | 비교적 웅성거리는 경향이 있어요 |

> ⚠️ 표현 원칙: "대체로", "경향", "편이에요" 등 확률적 표현만 사용. "항상", "절대" 등 단정 금지.

## 2. 시간대별 추천 (휴리스틱)

시간대별 잠재적 조용함은 경험적 추정입니다.
**사실로 단정하지 않으며, 실제 방문 경험과 다를 수 있음을 명시합니다.**

| 시간대 | 설명 문구 |
|--------|-----------|
| 지금 (now) | 현재 시간 기준으로 추천드려요 |
| 오전 (morning) | 오전에는 대체로 한적한 경향이 있어요 |
| 오후 (afternoon) | 오후에는 방문객이 늘 수 있어요 |
| 저녁 (evening) | 저녁에는 분위기가 달라질 수 있어요 |

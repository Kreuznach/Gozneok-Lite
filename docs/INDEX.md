## 이번 업데이트에서 무엇이 바뀌었나요? (2026-09-10)

> 이 섹션은 처음 개발을 배우는 친구들도 이해할 수 있도록 쉽게 적었어요.

이 앱은 **토스(Toss)**라는 회사가 만든 **"앱인토스(Apps in Toss)"**라는 곳에서 실행되는 미니앱이에요.
미니앱을 만들 때는 **SDK**라는 "도구 상자"를 가져다 쓰는데, 이건 위치 정보 가져오기·광고 보여주기 같은 기능을
개발자가 매번 새로 만들지 않아도 되게 미리 만들어 둔 코드 모음이에요.

토스에서 "이제 SDK는 3.1 버전 이상을 써주세요!"라고 새로 안내했어요. 그래서 이번에 다음 작업을 했어요.

1. **SDK 업그레이드**: `2.1.1` → `3.4.0`(가장 최신 버전)으로 올렸어요.
2. **설정 파일 이름 변경**: SDK가 버전 3으로 바뀌면서 앱 설정 파일 이름도
   `granite.config.ts` → `apps-in-toss.config.ts`로 바뀌었어요. (마치 책 제목이 바뀐 것처럼, 안에 담긴
   설정 내용도 새 버전 규칙에 맞게 다시 정리했어요.)
3. **앱 이름·아이콘 관리 방법 변경**: 예전에는 코드 파일 안에 앱 이름·아이콘 주소를 적었는데, 이제는
   "토스 파트너 콘솔"이라는 웹사이트에서 직접 등록하도록 바뀌었어요.
4. **실행 테스트**: 개발 서버를 켜서 홈 화면과 설정 화면이 잘 나오는지 눈으로 확인했어요.
5. **배포 파일 재생성**: 실제로 토스에 올릴 수 있는 배포용 파일(`gozneok-lite.ait`)을 새 SDK 기준으로 다시 만들었어요.
6. **업데이트 안내 문구 갱신**: 앱의 설정 화면(앱 정보 → 마지막 업데이트)에 나오는 날짜와 문구를 오늘 날짜로 바꿨어요.
